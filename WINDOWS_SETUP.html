🪟 Windows 安裝指南

這版超簡單:裝好 Python,然後雙擊一個安裝檔,其餘(FFmpeg、套件、啟動)全自動。照下面做即可。

0先選一個版本

🪶 輕量版

較舊 / 沒有獨立顯卡的電腦。做逐字稿 ＋ AI 摘要,不裝約 2GB 的 torch,又小又快。

install-lite.bat

🧰 完整版

要分辨「誰說了哪句」(說話人辨識),或有 NVIDIA 顯卡想 GPU 加速。含 torch。

install-full.bat
💡 不確定選哪個?只是想把錄音變文字、做會議摘要 → 選輕量版就好。之後想升級成完整版,隨時雙擊 install-full.bat 即可,不用重來。

1安裝 Python

到官網下載 Python 3.11 或 3.12:

👉 python.org/downloads

⚠️ 最重要安裝第一個畫面,務必勾選 ☑ Add python.exe to PATH,再按 Install。沒勾的話下一步會失敗。
💡Windows 版 Python 已內含圖形介面所需的元件,不用另外裝其他東西。這是唯一需要手動裝的;之後 FFmpeg 跟一堆套件都會自動處理。

2下載專案

最建議(之後能一鍵更新):用 git clone。裝好 git 後,在你想放的地方(例如「文件」)開啟終端機,貼:

git clone https://github.com/Kamiyu94/VoxLog.git

這樣以後更新只要雙擊 update.bat 就好。

📦 沒有 git 也行(下載 ZIP)打開 GitHub 專案頁 → 綠色 <> Code → Download ZIP → 解壓縮。差別:ZIP 版之後沒辦法用 update.bat 一鍵更新(要重新下載 ZIP 覆蓋),見最後的「更新」段。
📁記住這個 VoxLog 資料夾放在哪、別把裡面的檔案拆開搬。整包要待在一起才能跑。

3雙擊安裝檔(全自動)

進到 VoxLog 資料夾,雙擊你選的那個安裝檔:

🪶 輕量版 → 雙擊 install-lite.bat

🧰 完整版 → 雙擊 install-full.bat

它會自動:偵測 Python → 裝 FFmpeg → 建環境、下載套件 → 裝完直接開 VoxLog。

🛡️若 Windows 跳出「已保護你的電腦」藍色視窗 → 點 其他資訊 → 仍要執行。(這是因為 .bat 沒有付費簽章,不是病毒。)
⏳ 完整版第一次會比較久完整版要下載 約 2GB 的 torch,網路要穩、請耐心等(可能 10 分鐘以上)。畫面停著沒動不是當機,是在下載,中途別關。輕量版沒有這 2GB,快很多。
🎙️ whisper.cpp 引擎已內建,免安裝輕量的 whisper.cpp 辨識引擎(適合較舊/沒有獨立顯卡的電腦)已經包在專案裡(bin\whispercpp-win\),不需另外下載或設定。辨識模型會在第一次轉錄時自動下載。
💡萬一第一次轉錄時說「找不到 ffmpeg」,把視窗關掉、再雙擊一次安裝檔就好(剛裝的 FFmpeg 需要重開才生效)。

4啟動與桌面捷徑

安裝完會自動開 App。以後要用,雙擊資料夾裡的 VoxLog.bat 即可(它是平常的啟動檔;安裝檔只在第一次或換版本時才用)。

做一個桌面捷徑(方便每天用)

在 VoxLog.bat 上按滑鼠右鍵 → 傳送到 → 桌面 (建立捷徑)。以後桌面點兩下就開。

⚠️要建的是「捷徑」。別把 VoxLog.bat 本身拖到桌面 —— 它一旦離開原資料夾就找不到程式、會打不開。
⌨️ 想用打字啟動?第一次雙擊安裝檔時,會自動註冊一個 voxlog 指令。之後在「命令提示字元」或 PowerShell 打 voxlog 按 Enter 就能啟動。(若沒反應,把終端機關掉重開一次再試。)

5填 API Key 開始用

程式打開後會自動建立設定檔,你不用碰任何檔案。在介面上:

① 選 AI 引擎(ChatGPT / Gemini / Claude)
② 在 Key 欄位貼上 API Key(跟 Kris 拿,或用自己的)
③ 按 「驗證」,變綠就成功(會自動存檔)
④ 載入音檔或 .md / 逐字稿 → 開始轉錄、校正、產生摘要

🗣️ 輕量版看到辨識引擎有些選項是灰的(🔒)?那些(含「說話人辨識」)要完整版才有。要用的話,雙擊資料夾裡的 install-full.bat 升級後重開 App 即可。只要逐字稿、不需要分辨誰在說話,維持輕量版、用「whisper.cpp」就好。
✓ 完成! 以後每次要用,雙擊桌面捷徑(或資料夾裡的 VoxLog.bat)即可,不必再重裝。

🔄之後怎麼更新到最新版

VoxLog 改版時更新很簡單,不會動到你的 API Key 和已裝好的環境。

git clone 的人(建議):雙擊 update.bat

進 VoxLog 資料夾,雙擊 update.bat。它會自動 git pull 取最新程式碼、判斷你是輕量還完整版、補裝新套件。看到「更新完成」就可以雙擊 VoxLog.bat 重開。

🔒你的 config.json(API Key)和 venv(環境)都不會被覆蓋。

下載 ZIP 的人:重新下載覆蓋

到 GitHub 專案頁 → <> Code → Download ZIP → 解壓後把檔案整包覆蓋到原本的 VoxLog 資料夾(跳出「是否取代」選全部取代)。然後雙擊 VoxLog.bat,它會自動偵測並補裝新套件。

⚠️ZIP 版無法用 update.bat(它需要 git)。想要一鍵更新的話,改用上面的 git clone 版本。

🚀有 NVIDIA 顯卡?GPU 加速(完整版・已自動)

語音轉錄用 NVIDIA 顯卡(GPU)會比 CPU 快好幾倍。只有完整版(含 torch)有這功能,而且你什麼都不用做 —— install-full.bat 會在安裝時自動偵測有沒有 NVIDIA 顯卡,有的話就自動換成 GPU 版。

✓ 偵測到 NVIDIA 顯卡 → 自動裝 CUDA(GPU)版,啟用加速
✓ 沒有顯卡 → 維持 CPU 版,一樣能用(只是較慢)
✓ 換裝那次會多下載約 2~3GB,屬正常

💡怎麼知道有沒有吃到 GPU?開始轉錄時看 Log 欄:印「使用裝置:CUDA(你的顯卡名)」就是用 GPU;印「使用裝置:CPU」就是用 CPU。

裝完還是只用 CPU?(故障排除)

幾乎都是同一個原因:NVIDIA 顯卡驅動太舊,撐不起新版 CUDA。解法:用 GeForce Experience 或到 NVIDIA 官網把驅動更新到最新,然後再雙擊一次 VoxLog.bat,它會自動再試一次換裝。

⚠️ 給工程師torch 已釘在 2.8.0(WhisperX 3.8.6 相容版),請勿手動 pip install 不帶版本號的 torch —— 會抓到最新版而讓 WhisperX 引擎出錯。
