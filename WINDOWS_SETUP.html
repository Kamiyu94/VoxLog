🪟 Windows 安裝指南

這版超簡單：裝好 Python,然後雙擊一個檔案,其餘(FFmpeg、套件、啟動)全自動。照下面做即可。

1安裝 Python 2下載專案 3雙擊 VoxLog.bat(全自動) 4建一個桌面捷徑 5填 API Key 開始用

1安裝 Python

到官網下載 Python 3.11 或 3.12:

👉 python.org/downloads

⚠️ 最重要安裝第一個畫面,務必勾選 ☑ Add python.exe to PATH,再按 Install。沒勾的話下一步會失敗。
💡Windows 版 Python 已內含圖形介面所需的元件,不用另外裝其他東西。這是唯一需要手動裝的;之後 FFmpeg 跟一堆套件都會自動處理。

2下載專案

最簡單(免安裝 git):

打開 GitHub 專案頁 → 綠色 <> Code 按鈕 → Download ZIP → 解壓縮到你想放的地方(例如「文件」資料夾)。

📁記住這個 VoxLog 資料夾放在哪、別把裡面的檔案拆開搬。整包要待在一起才能跑。

(進階)有裝 git 的話也可以:

git clone https://github.com/Kamiyu94/VoxLog.git

3雙擊 VoxLog.bat(全自動)

進到解壓好的 VoxLog 資料夾,找到 VoxLog.bat,滑鼠左鍵點兩下。就這樣 —— 它會自動幫你:

✓ 偵測 Python
✓ 自動安裝 FFmpeg
✓ 建立環境、下載所有需要的套件
✓ 裝完直接打開 VoxLog

⏳ 第一次會比較久它要下載 約 2GB 的語音模型套件,網路要穩、請耐心等(可能 10 分鐘以上)。畫面停著沒動不是當機,是在下載。中途別關。
🛡️若 Windows 跳出「已保護你的電腦」藍色視窗 → 點 其他資訊 → 仍要執行。(這是因為 .bat 沒有付費簽章,不是病毒。)
💡萬一第一次轉錄時說「找不到 ffmpeg」,把視窗關掉、再雙擊一次 VoxLog.bat 就好(剛裝的 FFmpeg 需要重開才生效)。

4建一個桌面捷徑(方便每天用)

不想每次都翻資料夾的話,做一個桌面捷徑:

在 VoxLog.bat 上按滑鼠右鍵 → 傳送到 → 桌面 (建立捷徑)。以後桌面點兩下就開。

⚠️要建的是「捷徑」。別把 VoxLog.bat 本身拖到桌面 —— 它一旦離開原資料夾就找不到程式、會打不開。

5填 API Key 開始用

程式打開後會自動建立設定檔,你不用碰任何檔案。在介面上:

① 選 AI 引擎(ChatGPT / Gemini / Claude)
② 在 Key 欄位貼上 API Key(跟 Kris 拿,或用自己的)
③ 按 「驗證」,變綠就成功(會自動存檔)
④ 載入音檔或 .md / 逐字稿 → 開始轉錄、校正、產生摘要

✓ 完成! 以後每次要用,就雙擊桌面捷徑(或資料夾裡的 VoxLog.bat)即可,不必再重裝。

小提醒:若電腦有 NVIDIA 顯卡,語音轉錄會快很多(預設是 CPU 版,較慢但可用)。若只想用「載入 .md 做摘要」這類 AI 功能,不轉錄語音的話會更快。
