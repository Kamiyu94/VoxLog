🪟 Windows 安裝指南

這版超簡單：裝好 Python,然後雙擊一個檔案,其餘(FFmpeg、套件、啟動)全自動。照下面做即可。

1安裝 Python 2下載專案 3雙擊 VoxLog.bat(全自動) 4建一個桌面捷徑 5填 API Key 開始用 🔄之後怎麼更新到最新版

1安裝 Python

到官網下載 Python 3.11 或 3.12:

👉 python.org/downloads

⚠️ 最重要安裝第一個畫面,務必勾選 ☑ Add python.exe to PATH,再按 Install。沒勾的話下一步會失敗。
💡Windows 版 Python 已內含圖形介面所需的元件,不用另外裝其他東西。這是唯一需要手動裝的;之後 FFmpeg 跟一堆套件都會自動處理。

2下載專案

最簡單(免安裝 git):

打開 GitHub 專案頁 → 綠色 <> Code 按鈕 → Download ZIP → 解壓縮到你想放的地方(例如「文件」資料夾)。

📁記住這個 VoxLog 資料夾放在哪、別把裡面的檔案拆開搬。整包要待在一起才能跑。

(進階)有裝 git 的話也可以:

git clone https://github.com/Kamiyu94/VoxLog.git

3雙擊 VoxLog.bat(全自動)

進到解壓好的 VoxLog 資料夾,找到 VoxLog.bat,滑鼠左鍵點兩下。就這樣 —— 它會自動幫你:

✓ 偵測 Python
✓ 自動安裝 FFmpeg
✓ 建立環境、下載所有需要的套件
✓ 裝完直接打開 VoxLog

⏳ 第一次會比較久它要下載 約 2GB 的語音模型套件,網路要穩、請耐心等(可能 10 分鐘以上)。畫面停著沒動不是當機,是在下載。中途別關。
🛡️若 Windows 跳出「已保護你的電腦」藍色視窗 → 點 其他資訊 → 仍要執行。(這是因為 .bat 沒有付費簽章,不是病毒。)
💡萬一第一次轉錄時說「找不到 ffmpeg」,把視窗關掉、再雙擊一次 VoxLog.bat 就好(剛裝的 FFmpeg 需要重開才生效)。

4建一個桌面捷徑(方便每天用)

不想每次都翻資料夾的話,做一個桌面捷徑:

在 VoxLog.bat 上按滑鼠右鍵 → 傳送到 → 桌面 (建立捷徑)。以後桌面點兩下就開。

⚠️要建的是「捷徑」。別把 VoxLog.bat 本身拖到桌面 —— 它一旦離開原資料夾就找不到程式、會打不開。
⌨️ 想用打字啟動?第一次雙擊後就行了你第一次雙擊 VoxLog.bat 時,它會自動註冊一個 voxlog 指令。之後在「命令提示字元」或 PowerShell 任何位置打 voxlog 按 Enter,就能啟動,不用翻資料夾。(若打了沒反應,把終端機關掉重開一次再試 —— 剛註冊的指令需要新開的視窗才認得。)

5填 API Key 開始用

程式打開後會自動建立設定檔,你不用碰任何檔案。在介面上:

① 選 AI 引擎(ChatGPT / Gemini / Claude)
② 在 Key 欄位貼上 API Key(跟 Kris 拿,或用自己的)
③ 按 「驗證」,變綠就成功(會自動存檔)
④ 載入音檔或 .md / 逐字稿 → 開始轉錄、校正、產生摘要

✓ 完成! 以後每次要用,就雙擊桌面捷徑(或資料夾裡的 VoxLog.bat)即可,不必再重裝。

🔄之後怎麼更新到最新版

VoxLog 改版時更新很簡單,不會動到你的 API Key 和已裝好的環境(它們不在下載檔裡)。

① 拿到新版檔案

當初用「下載 ZIP」的人(多數):到 GitHub 專案頁 → 綠色 <> Code → Download ZIP → 解壓縮後,把裡面的檔案整包覆蓋到你原本的 VoxLog 資料夾(跳出「是否取代檔案」就選 全部取代)。

🔒你的 venv(已下載約 2GB 的環境)和 config.json(API Key)不在 ZIP 裡,不會被覆蓋,放心覆蓋。

當初用 git clone 的人:進 VoxLog 資料夾、在網址列打 cmd 按 Enter 開終端機,貼這行:

git pull

② 雙擊 VoxLog.bat(或打 voxlog)

覆蓋完,照常雙擊 VoxLog.bat(或桌面捷徑、或打 voxlog)。它會自動偵測有沒有新增套件、需要的話補裝,然後開啟,新功能就生效了。

⏳更新後第一次啟動,若有新套件會花幾秒補裝(畫面顯示「安裝/更新相依套件中」是正常的),裝完會自動開,不用做別的。
✨ 最近這版多了什麼
  • 完成後自動開檔:逐字稿、AI 校正、摘要做完會自動用預設程式打開給你看,不用自己去資料夾找。
  • 摘要改成 Word 檔(.docx):「產生摘要」現在直接輸出 _摘要.docx,Word 直接開,標題、清單、待辦表格都排好。
  • 低階電腦更穩:預設轉錄模型改為較省記憶體的 small,記憶體小的電腦不會一跑就閃退(要更高精度再在介面手動選 medium/large)。
  • 打 voxlog 就能啟動:不想翻資料夾的話,終端機打 voxlog 即可開(見步驟 4 說明)。

小提醒:若電腦有 NVIDIA 顯卡,語音轉錄會快很多(預設是 CPU 版,較慢但可用)。若只想用「載入 .md 做摘要」這類 AI 功能,不轉錄語音的話會更快。
