🪟 Windows 安裝指南

照著下面 4 步做即可。指令右上角的「複製」可一鍵複製,貼到終端機(命令提示字元 / PowerShell)按 Enter 執行。

1安裝 Python 2安裝 FFmpeg 3下載專案 4安裝套件並啟動 5開起來之後

1安裝 Python

到官網下載 Python 3.11 或 3.12:

👉 python.org/downloads

⚠️ 最重要安裝第一個畫面,務必勾選 ☑ Add python.exe to PATH,再按 Install。沒勾的話後面指令全部會失敗。
💡Windows 版 Python 已內含圖形介面所需的 tkinter,不用另外裝其他東西。

2安裝 FFmpeg

開啟 PowerShell(開始選單搜尋 "PowerShell"),貼上這行:

winget install Gyan.FFmpeg
💡裝完請關掉終端機再重開,讓設定生效。程式也會自動尋找 FFmpeg,所以裝了就行。

3下載專案

方法 A — 有安裝 git:

git clone https://github.com/Kamiyu94/VoxLog.git
cd VoxLog

方法 B — 沒有 git(最簡單):

打開 GitHub 專案頁 → 綠色 <> Code 按鈕 → Download ZIP → 解壓縮 → 進到資料夾,在上方網址列輸入 cmd 按 Enter,就會在這個資料夾開啟終端機。

4安裝套件並啟動

在專案資料夾的終端機,依序執行:

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python transcribe_gui.py
⏳pip install 會下載 torch 約 2GB,網路要穩、請耐心等(可能 10 分鐘以上)。這是語音轉錄必需的。

之後要再次開啟程式,只要在資料夾終端機執行:

venv\Scripts\activate
python transcribe_gui.py

5開起來之後

程式啟動瞬間會自動建立設定檔,你不用碰任何檔案。接著在介面上:

① 選 AI 引擎(ChatGPT / Gemini / Claude)
② 在 Key 欄位貼上自己的 API Key
③ 按 「驗證」,變綠就代表成功(會自動存檔)
④ 載入音檔或 .md / 逐字稿 → 開始轉錄、校正、產生摘要

✓ 完成! 之後每次使用都從第 4 步最後那兩行(啟動指令)開始即可。

小提醒:若電腦有 NVIDIA 顯卡,語音轉錄會快很多(預設是 CPU 版,較慢但可用)。若只想用「載入 .md 做摘要」這類 AI 功能,其實不裝 torch 也能開,但要完整語音轉錄就得照第 4 步裝齊。
