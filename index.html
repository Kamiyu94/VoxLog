這是什麼

丟一段錄音、一支影片、或一條 YouTube 網址進去，VoxLog 會自動聽寫成逐字稿，再用 AI 幫你整理成一份可以直接交出去的會議紀錄（Word 檔）。

🎙 語音轉逐字稿

錄音檔、影片檔都吃，也可以直接貼 YouTube 網址。

🗣 分辨誰在說話

標出「誰說了哪一句」（完整版功能）。

🤖 AI 整理會議紀錄

自動修錯字、抓重點與待辦，輸出成 Word 檔。

📺 字幕檔

順手切成 SRT 字幕，影片可以直接用。

💡AI 整理那一段需要你自己的 AI 帳號金鑰（Claude、Gemini、ChatGPT 擇一），裝好後在畫面上貼一次就好。不想用雲端 AI 的話，也可以接自己電腦上的 Ollama／LM Studio。

3照著做

☝️先選上面兩題，這裡就會出現你這台電腦專屬的步驟。

✅

先裝 Python（只有第一次要做）

到 Python 官網下載安裝，安裝畫面最下面那個「Add python.exe to PATH」一定要打勾，再按 Install Now。

前往 Python 官網 ↗

請裝 3.11 或 3.12 版。忘記打勾的話，重新執行一次安裝檔選 Modify 就能補勾。

下載 VoxLog

按下面的按鈕會開啟 Google 雲端硬碟，點右上角的下載圖示存下 VoxLog.zip，再解壓縮成一個 VoxLog 資料夾。

⬇ 下載 VoxLog.zip

Windows 解壓縮：對 zip 按右鍵 →「解壓縮全部」。解出來如果多一個 __MACOSX 資料夾，那是壓縮時附帶的，忽略或刪掉都行，要打開的是 VoxLog 那個。

⚠解壓縮後把整個資料夾搬到「文件」或「應用程式」裡再開始安裝，別留在「下載」資料夾直接跑——之後很容易被自己清掉。

雙擊安裝檔

打開 VoxLog 資料夾，雙擊 ，然後就放著讓它跑。

⚠如果跳出「無法打開，因為來自未識別的開發者」——對著同一個檔案按右鍵 → 選「打開」，再按一次視窗裡的「打開」就會過。這個只要做一次。
  • 中途可能跳出 Apple 的「安裝命令列工具」小視窗 → 按 Install。
  • 可能要輸入這台電腦的開機密碼（它在裝 Homebrew，打字時不會顯示，直接打完按 Enter）。
⚠如果跳出藍色的「Windows 已保護您的電腦」——點「其他資訊」→「仍要執行」。

整個過程會一直印字，大約 5～15 分鐘大約 15～40 分鐘（要下載好幾 GB，網路慢會更久）。看到「安裝完成」再關掉視窗。

啟動 VoxLog

以後每次要用，就雙擊資料夾裡的 。

習慣用終端機的話，打 voxlog 也能啟動。

貼上 AI 金鑰（只做一次）

第一次打開，在畫面上選一個 AI 引擎（Claude／Gemini／ChatGPT），把你的 API 金鑰貼進去，按「驗證」，通過後就會自動存起來，下次不用再貼。

只做逐字稿、不需要 AI 整理的話，這步可以先跳過。

開通「分辨誰在說話」（免費，只做一次）

這個功能用的模型要求先註冊同意，三步：

  • 到 huggingface.co 建立 Token ↗，建立時勾選 Read access to public gated repositories。
  • 用同一個帳號到這兩頁，各按一次 Agree and access repository：
    speaker-diarization-community-1 ↗
    segmentation-3.0 ↗
  • 回到 VoxLog，把 Token 貼進「HuggingFace Token」欄位。
⚠一定要同意 community-1 那一頁；只同意舊版的 speaker-diarization-3.1 沒有用。

以後怎麼更新

🔄之後 VoxLog 出新版，雙擊資料夾裡的 就會自動抓最新版、順便補裝需要的東西。不用回來重新下載整包，你貼過的 API 金鑰和已經下載好的模型也都不會被動到。
⚠Windows 第一次更新前要先裝 git：在 PowerShell 打 winget install Git.Git，或到 git-scm.com 下載安裝。裝好再雙擊 update.bat。
進階：想自己用 git 抓

不想經過雲端硬碟的話，直接 clone 也可以，內容一樣：

git clone https://github.com/Kamiyu94/VoxLog.git

抓下來之後，一樣雙擊 安裝。

裝不起來？Mac 常見狀況
  • 一打開就閃退：多半是系統內建的舊 Python 造成的，安裝檔會自動換成正確版本；請確認你是雙擊安裝檔跑完，而不是自己手動裝。
  • 「分人」功能報錯：完整版安裝檔已自動處理 Mac 上的兩個相容性問題；若之後跑過 brew upgrade 可能要重跑一次安裝檔。
  • 更完整的說明與逐步截圖在 macOS 安裝指南。
裝不起來？Windows 常見狀況
  • 說找不到 python：安裝 Python 時沒勾「Add python.exe to PATH」。重跑一次 Python 安裝檔選 Modify 補勾，再重來。
  • 視窗一閃就關掉：改成對安裝檔按右鍵 →「以系統管理員身分執行」試一次。
  • 更完整的說明在 Windows 安裝指南。
