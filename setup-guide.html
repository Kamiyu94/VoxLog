安裝 Python 3.12

下載 Python 3.12

前往官網下載 3.12.x 安裝檔（勿使用 3.13+）：

https://www.python.org/downloads/release/python-3129/

安裝時勾選「Add Python to PATH」

Windows 安裝程式底部的 checkbox，務必打勾，否則終端機找不到 python 指令。

確認安裝成功

python --version
# 應顯示 Python 3.12.x
⚠️ 若電腦已有 Python 3.13 或 3.14，建議另開虛擬環境（python3.12 -m venv venv）再裝套件，避免版本衝突。
3

安裝 FFmpeg

Whisper 轉錄音訊前需要 FFmpeg 做格式轉換，沒有它就無法讀取 mp4/m4a 等格式。

Windows（推薦：WinGet）
winget install Gyan.FFmpeg

安裝後重新開啟終端機即可，PATH 會自動設定。

macOS（推薦：Homebrew）
brew install ffmpeg
確認安裝
ffmpeg -version
# 應顯示版本號，例如 ffmpeg version 8.x
4

安裝 Python 套件

以下指令請在終端機（PowerShell / Terminal）執行，進入 VoxLog 資料夾後依序安裝。

必裝套件（核心功能）
pip install customtkinter pillow requests opencc-python-reimplemented
Whisper 引擎（擇一或兩者都裝）
# 引擎 A：標準 Whisper（較穩定）
pip install openai-whisper

# 引擎 B：WhisperX（較快，支援說話人分離）
pip install whisperx
⚠️ 裝完 whisperx 後，它會把 PyTorch 覆蓋回 CPU 版。如有 NVIDIA GPU，裝完後必須重新執行第 5 節的 CUDA 版 PyTorch 指令。
引擎 C：whisper.cpp（MacBook Air／8GB 機器建議）

輕量、記憶體佔用極低（約 1GB，且不隨錄音長度增加），在 Apple Silicon 用 Metal 加速。不是 pip 套件，要用 Homebrew 裝（不是 Python 套件，所以不在 requirements.txt 裡）。

# macOS
brew install whisper-cpp
💡 MacBook Air / 8GB 記憶體的機器，VoxLog 第一次啟動會自動把辨識引擎選成「whisper.cpp」，所以這台務必先裝好。辨識模型（預設 medium）會在第一次轉錄時自動下載，不用手動處理。whisper.cpp 沒有內建說話人分離，可改用第二步驟的「自動標註說話方」由 AI 依內容判斷。
YouTube 下載功能（選用）
pip install yt-dlp

不需要此功能可跳過，App 不會因此無法啟動。

雲端 AI 套件（選用，依使用的引擎安裝）
# Claude（Anthropic）
pip install anthropic

# Gemini（Google）— 注意：只裝新版 SDK，兩個不能共存
pip uninstall google-generativeai google-genai -y
pip install google-genai

使用 Ollama 本地 AI 時不需要安裝任何 AI 套件。

NVIDIA GPU 加速（選用）

沒有 NVIDIA GPU 可跳過此節，App 會自動退回 CPU 模式。

確認驅動版本支援 CUDA 12.4

nvidia-smi
# 右上角應顯示 CUDA Version: 12.x 以上

若版本過低，請先至 NVIDIA 官網更新顯示卡驅動。

安裝 CUDA 12.4 版 PyTorch

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124

此步驟必須在裝完 whisperx 之後執行，否則會被蓋回 CPU 版。

確認 GPU 可用

python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
# 應顯示 True  NVIDIA GeForce RTX xxxx
ℹ️ RTX 4060（8GB VRAM）建議使用 large-v3 模型，設定 int8_float16，batch size 8，約每分鐘音訊 15 秒完成。

安裝 Ollama 本地 AI（選用）

🔒 使用 Ollama 時，所有資料完全在本機處理，不會上傳到任何雲端服務。適合處理含有個資或敏感內容的錄音。

下載並安裝 Ollama

https://ollama.com/download

Windows / macOS 均有安裝包，安裝後會在背景自動啟動服務（port 11434）。

下載繁體中文友善模型（擇一）

# 推薦：繁中支援最好，7B 約 4.7GB
ollama pull qwen2.5:7b

# 備選：較大但品質更好
ollama pull qwen2.5:14b

# 備選：Google 出品，繁中品質不錯
ollama pull gemma3:12b

首次下載需要時間，視網速而定，之後每次都是本機推理。

確認 Ollama 服務運作

# 終端機輸入，應看到已下載的模型清單
ollama list

模型選擇參考

模型名稱大小繁中品質建議用途
qwen2.5:7b4.7 GB★★★★☆ 校正逐字稿、SRT 切句（推薦入門）
qwen2.5:14b9 GB★★★★★ 摘要、高品質校正（需 12GB+ VRAM 或 RAM）
gemma3:12b8.1 GB★★★★☆ 摘要產生（Google 模型）
llama3.2:3b2 GB★★★☆☆ 低階機器測試用，中文較弱
⚠️ 本地模型的摘要與校正品質低於 Claude / Gemini，建議先用 qwen2.5:7b 試跑，評估品質後再決定是否升級模型。
7

HuggingFace Token（說話人分離）

只有使用 WhisperX 引擎並開啟說話人分離時才需要。引擎 A（Whisper）不需要。

建立 HuggingFace 帳號並產生 Token

前往 https://huggingface.co/settings/tokens，建立 token，並勾選 「Read access to public gated repositories」。

接受以下兩個模型的使用條款

https://huggingface.co/pyannote/speaker-diarization-community-1
https://huggingface.co/pyannote/segmentation-3.0

進入各模型頁面，點選「Agree and access repository」。

將 Token 填入 VoxLog

啟動 App 後，在「HuggingFace Token」欄位貼上 token，App 會自動儲存到 config.json。

雲端 AI API Key（選用）

選擇 Ollama 本地 AI 時完全不需要以下任何 Key。以下為雲端引擎說明：

Ollama
完全本地
  • 不需要 API Key
  • 在「Model 名稱」欄填模型名稱
  • 例：qwen2.5:7b
  • 資料不離開本機
Claude
雲端
  • 需要 Anthropic API Key
  • 取得：console.anthropic.com
  • 摘要與校正品質最佳
  • 依 token 計費
Gemini
雲端
  • 需要 Google API Key
  • 取得：aistudio.google.com
  • 使用 gemini-3.1-flash-lite
  • 有免費額度，SRT 切句推薦
💡 Key 只需在 App 中填寫一次，會自動儲存到同目錄的 config.json。請不要將此檔案上傳到 GitHub 或分享給他人。

啟動 VoxLog

方法一：雙擊 run.bat（Windows 推薦）

直接雙擊 VoxLog 資料夾中的 run.bat 即可啟動。

方法二：終端機啟動
cd C:\path\to\VoxLog
python transcribe_gui.py
ℹ️ 第一次使用 Whisper 或 WhisperX 時，App 會自動下載模型到本機快取（large-v3 約 3 GB），需要等待幾分鐘，之後每次啟動都是直接從快取載入。
10

使用流程

選擇音訊 / 影片檔案

點「選擇檔案」，支援 .m4a .mp3 .wav .ogg .flac .mp4 .mkv .avi .mov .webm。

或在 YouTube 網址列貼上影片連結，點「下載並轉錄」（需安裝 yt-dlp）。

選擇轉錄引擎與模型

Whisper：穩定，無說話人分離。
WhisperX：較快，支援辨識多位說話者（需 HuggingFace Token）。

模型建議：small（預設，快又省記憶體）、medium（較準）、large（最準最慢）。記憶體小（如 8GB）請用 small；GUI 的「轉錄模型」旁有 ⓘ 說明可參考。

開始轉錄

點「開始轉錄」，進度條會即時更新。完成後自動產生 _transcript.txt，若勾選「輸出 SRT」則另產生字幕檔。

AI 後製（選用）

選擇 AI 引擎（Claude / Gemini / ChatGPT，或本機的 Ollama / LM Studio）後可執行：

  • 校正逐字稿：修正空耳錯字，產生 _transcript_corrected.txt
  • 產生摘要：整理重點、人物、議題，產生 Word 檔 _摘要.docx
  • 匯出 SRT：語意切句，輸出適合後製的字幕 SRT

常見問題

❌ ModuleNotFoundError: No module named 'whisper'
pip install openai-whisper
❌ torch.cuda.is_available() 回傳 False（有 NVIDIA GPU）

PyTorch 被 whisperx 覆蓋回 CPU 版，重新安裝 CUDA 版：

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
❌ Ollama 連線失敗 / requests.ConnectionError

Ollama 服務未啟動，開啟終端機手動啟動：

ollama serve

或確認系統匣中 Ollama 圖示是否存在（Windows 安裝後通常自動背景執行）。

❌ Gemini API 回傳 404 或 limit: 0

部分 Gemini 模型在免費額度限制。VoxLog 使用 gemini-3.1-flash-lite，若仍有問題請確認 Google AI Studio 中帳號的 API 配額狀態。

❌ 說話人分離失敗 / 401 Unauthorized

HuggingFace Token 未設定，或未在以下兩個模型頁面接受使用條款：

pyannote/speaker-diarization-community-1
pyannote/segmentation-3.0
❌ ffmpeg not found 或音訊格式無法讀取

FFmpeg 未安裝或不在 PATH 中。執行 ffmpeg -version 確認，若無回應請重新安裝並重啟終端機。
